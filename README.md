# Hedgefun smart contracts

The Solidity contracts for Hedgefun's strategy-token launchpad live in [`contractV1/`](./contractV1/README.md). The version directory is a self-contained Foundry project with source code, selected tests, ABIs, and pinned dependencies.

The original source snapshot is commit `5c28050cae10e73166aa993bdfe3c2cbf0b71823`. Contract source files are copied without Solidity changes. This repository omits deployment credentials, broadcast data, operations, and third-party reference source.

The original Hedgefun Solidity files are MIT licensed. Dependencies are Git submodules and retain their own licenses and copyright notices; see their repositories for terms.
