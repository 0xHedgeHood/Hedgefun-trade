03

多人交易压力测试

真实 V2 合约 · 本地 EVM

选择一个经典场景，现场重放同一时间戳下的不同交易排序。每次都运行合约测试；显示的是实际成交与税费，不是上方数学模型的推算。

01 / BUY WAVE

多人抢买

四个钱包同时递交买单。比较先后顺序、每人到账，以及临近毕业时的部分成交退款。

02 / SELL WAVE

多人抢卖

四个钱包依次卖出。对照曲线、毕业后 V4 池，以及测试中由国库身份直接触发的卖税峰值；这里不执行真实回购。

03 / MIXED ORDER

有人买，有人卖

两买两卖交错执行。比较买单先到与卖单先到时，卖方实际拿到的股票。

04 / OPENING SNIPER

开盘狙击者

机器人先买、用户跟买、机器人退出；逐秒比较 3 秒买入税下的净收益，并测试 1% 与 0.1% 限滑是否挡得住小额夹击。

这里用真实 V2 曲线、路由、Hook 和 V4 PoolManager，但股票与喂价是测试替身；与上面的 Robinhood 固定区块 Fork 不同。EVM 交易仍逐笔执行，“同时”只表示同一时间戳并比较排序。结果不包含真实区块打包、抢跑费用、MEV 竞争或链上广播。

04

统一价格开盘实验

研究模型 · 非合约执行

假设开盘前 3 个区块收集买单，再按同一价格分配。输入机器人和用户买单，对照当前逐笔曲线、直接聚合买单，以及清算价与批后现价对齐的方案。每笔用户订单保留最低净到账：不满足就整笔退款。

这是连续数学模拟。主对照把统一价视为替代 3 秒高买税，因此批次按普通 10% 买税、10% 卖税计算；下方另显示保留 66% 高买税的结果。现行逐笔对照用第 1 秒 66% 买税。模型不包含真实收单合约、撤单、Gas、区块构建者费用或毕业。清算价对齐方案会改变现有曲线的固定不变量，尚不能部署。
