# HedgeFun、Long、StonkFun：机制对比

核对日期：2026-10-03。比较的是可观察到的产品与资金流机制，不是投资收益排名，也不是对竞品合约的安全审计。

## 结论

**股票配对、LP 手续费和烧币都不能单独当作 HedgeFun 的独有优势。** Long 的官方产品已经展示股票配对、社区金库与手续费循环；StonkFun 的官方条款也明确描述交易费、奖励与回购。

HedgeFun 当前最有辨识度的组合是：每个发行币有独立国库，创建者选择股票价格触发规则，keeper 按确定顺序处理止损、止盈、补仓；利润及该币 LP 股票侧手续费进入该币回购预算，FUN 侧 LP 手续费直接烧毁。这提供可验证的资产管理与回购过程，但不保证币价下限或超额收益。

## 已核实的竞品行为

## 我们可以证明什么

| HedgeFun 能力 | 对用户的具体价值 | 不能延伸成的宣传 |
|---|---|---|
| 每币独立的参数与库存账本 | 能追踪本币持有什么、按什么价格规则卖出/买入 | 不能说竞品绝无类似功能；本次没有穷尽所有竞品版本 |
| 股票价格触发的止盈、止损、补仓 | 有现货仓位时，股票路径可产生策略交易，利润可成为回购资金 | 止损保护国库仓位，不是 FUN 的保本或币价止损 |
| LP 两侧费用有明确去向 | stock fee 进入本币 buybackStock；FUN fee 直接减少总供给 | 回购自己付出的 LP 费不能再次算作外部新增收入 |
| 策略、LP 领取和回购可由任意调用者推进 | 健康状态、额度及冷却允许时，不要求某个指定 keeper | 无人调用仍不会执行；V2 买税 FUN 的 `convertFees` 另需 factory owner，不能把整条费用链说成完全无需管理者 |
| 真实合约日线重放与资金核对 | 可检查参数、动作、费用、币价、国库与 LP 资产之间的传导 | 测试通过不是“收益更高”，日线重放不是可实现收益承诺 |

## 优势伴随的成本

国库留存资金会影响可投入 LP 的资金量；在相同总融资额下必须比较退出深度，而不能只比边际币价。策略也增加现货换仓费用、预言机依赖、keeper 执行成本与维护复杂度。止盈可能过早离场，止损后可能错过反弹，窄阈值可能被手续费吞掉。V2 买税 FUN 转换成 stock 会形成卖盘，且需要 owner 主动执行；只模拟回购而漏掉这笔卖盘会偏高估计币价效果。

我们的单币国库是可验证的机制差异。更低回撤、更高币价、更好成交、更多真实用户，均需要各自证据；当前测试网数据不足以证明比 Long 或 StonkFun 的实盘结果更好。最有依据的产品表达是“可查看规则和执行记录的股票策略币”，而不是“股票配对一定涨”或“回购必然盈利”。

本轮多股票 2025 日线实验专门加入相同订单流的无策略基准、手续费领取开关和未领取费用估值，检验上述潜在优势是否在给定情景中成立。它没有重建竞品合约，不能用来宣布战胜竞品。
