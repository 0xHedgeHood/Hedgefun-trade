# v2load：Go 离线并发测试 CLI

用于虚拟用户的整数账本压力测试：默认40个用户、40个并发客户端、每用户25轮请求。
虚拟用户是整数索引，资产是 synthetic units，没有真实币种或资金价值。
工具没有网络/RPC、钱包、私钥、签名、交易广播或价格曲线功能。

本模型采用3%基础费，费用内20%协议、10%创作者、余数归金库。它是固定规则的测试模型，
不执行EVM合约，也不证明现有V1/V2池的收费行为、开盘分配、公平排序、MEV保护或链上吞吐。
实际合约验证继续使用仓库的Foundry测试。

## 构建和运行

需要已安装Go 1.26.0或更新版本。模块只使用标准库，没有第三方依赖。
以下设置禁止Go自动下载工具链和模块；未安装合适编译器时会直接报错。

```sh
cd tools/v2load
GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go build -o bin/v2load ./cmd/v2load
./bin/v2load run --users 40 --workers 40 --rounds 25
./bin/v2load run --users 40 --workers 40 --rounds 25 --json
```

你的机器如果同时安装多个Go版本，请让上述 `go` 指向1.26或更新的编译器。
二进制本身运行时不需要Go或区块链节点。

## 测试规则和默认结果

每笔请求支付10,000单位；接受后9,700归本金，协议60、创作者30、金库210。
用户初始余额足够覆盖自己的全部请求。每第10轮注入过期请求；每第17轮注入最低到账要求
高于可得credit的请求。两种错误重合时过期优先。拒绝请求不扣账、不收手续费，也不消耗请求ID。
同一ID接受后不能再次扣账，即使用户或其它字段发生变化；这不是返回原结果的完整幂等接口。

默认1,000个请求的确定性结果：880接受、80过期拒绝、40最低到账拒绝。
原始10,000,000单位分成：用户剩余1,200,000、本金8,536,000、协议52,800、
创作者26,400、金库184,800；五项之和保持不变。

并发客户端通过有界队列提交请求；账本在互斥锁内原子地验证和更新。
请求处理次序随调度改变，完整运行的计数和金额不随worker数量改变。
报告核对资金守恒、角色分账、每用户余额、完整工作量及统一收费规则。
拒绝路径的零写入、重复ID竞争和低余额竞争由单元测试另外验证。

## 参数和退出状态

| 参数 | 默认 | 上限/含义 |
|---|---:|---|
| `--users` | 40 | 1–10,000个虚拟用户 |
| `--workers` | 40 | 1–256个客户端goroutine |
| `--rounds` | 25 | 1–10,000轮；用户数乘轮数不超过1,000,000 |
| `--timeout` | 30s | 1ms–5m的总时限 |
| `--json` | false | 标准输出JSON，错误写标准错误 |

`version` 打印工具版本；`--help` 列出参数。未识别的位置参数、未知参数或超限配置均在运行前拒绝。
取消或超时会等待已开始的处理收尾，再输出实际submitted/completed计数与最终账本。
排队但未完成的请求不会算成规则拒绝。部分运行的完整工作量和统一规则检查为false。
即使请求已全部处理，收尾期间的取消或超时也不会报告passed。

| 退出码 | 含义 |
|---:|---|
| 0 | 完整测试及全部检查通过；或help/version |
| 1 | 账本不变量或输出写入失败 |
| 2 | 参数无效 |
| 124 | 收到取消信号或超过时限 |

JSON的 `schema_version=1`、`mode=offline-synthetic-fee-ledger`。`elapsed_ns` 是本机模型运行耗时，
不能当作网络或链上执行延迟；CLI不输出真实持仓、收益或抢筹比例。

## 验证

```sh
GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go test -race -count=1 ./...
GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go vet ./...
GOTOOLCHAIN=local GOPROXY=off GOSUMDB=off go test ./internal/ledger -fuzz FuzzAccounting -fuzztime 5s
```

测试覆盖40用户并发、跨用户重复ID、超额支出竞争、uint64边界、独立大整数费用计算、
全部拒绝原因的快照回滚、快照隔离、169/170轮错误优先级、取消、参数和输出失败。
